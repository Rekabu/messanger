# 💬 Мессенджер на Flask + Socket.IO

Полноценный веб-мессенджер с личными и групповыми чатами, 
авторизацией, статусами прочтения и онлайн, загрузкой файлов.

## Живой сайт 

https://messanger-bhb4.onrender.com/

## ✨ Возможности

- 🔐 **Авторизация** — регистрация и вход, пароли хешируются
- 💬 **Личные сообщения** — чат один на один
- 👥 **Группы** — создание групповых чатов, приглашение участников
- 📢 **Общий чат** — для всех пользователей
- ✅ **Статус прочитано** — галочки, как в Telegram
- 🟢 **Статус онлайн** — видно, кто сейчас в сети
- ✏️ **Редактирование** — изменение своих сообщений
- 🗑️ **Удаление** — удаление своих сообщений
- 📎 **Загрузка файлов** — фото, документы, видео, аудио (до 15 МБ)
- 🔍 **Пагинация** — подгрузка старых сообщений
- ⌨️ **Индикатор набора** — видно, когда кто-то печатает

## 🛠 Технологии

- **Python 3** — язык программирования
- **Flask** — веб-фреймворк
- **Flask-SocketIO** — WebSocket для реального времени
- **Eventlet** — асинхронный воркер для Gunicorn
- **SQLite** — база данных
- **HTML, CSS, JavaScript** — интерфейс
- **Werkzeug** — хеширование паролей
- **Render** — хостинг
